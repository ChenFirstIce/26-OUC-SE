# 阿尔茨海默病认知评估问卷管理系统 — PPT大纲

---

## 第一部分：前期准备（3~4 张）

**Slide 1 — 选题背景**
- 问题背景：阿尔茨海默病及主观认知下降（SCD）筛查需求增长
- 传统纸质量表效率低、难存档、无法AI辅助
- 解决思路：Web化、智能化的认知评估平台

**Slide 2 — 需求调研**
- 参考量表：SCD-Q9、MoCA-B、Boston命名测试、STT形状连线测试、GDS-15等
- 核心需求：医生管理 + 患者自评 + AI辅助 + 数据可视化
- 原始资料整理（6份临床量表PDF + 参考文献）

**Slide 3 — 技术选型过程**

- 前端调研：Vue 3 vs React → 统一选 Vue 3 + Element Plus
- 后端调研：FastAPI 异步性能优势
- AI接入：DeepSeek API（国产大模型，访问稳定）
- 数据库：SQLite (开发) / 可配置 PostgreSQL (生产)

**Slide 4 — 项目规划**

- 三阶段计划：
  1. MVP（医生+患者基础流程）
  2. 辅助任务（B类程序辅助 + C类AI辅助）
  3. 整合优化（多分支合并、性能优化）

## 第三部分：技术路线（3~4 张）

~~**Slide 7 — 系统整体架构图**~~

**Slide 8 — 核心技术栈**

- **前端**：Vue 3.5 + TypeScript + Element Plus + ECharts + Vite
- **后端**：FastAPI 0.124 + SQLAlchemy + Pydantic + PyJWT + Fernet加密
- **AI**：DeepSeek API（SCD访谈、MoCA-B评分）+ 本地降级机制
- **数据库**：SQLite（开发）/ PostgreSQL（生产）+ Alembic迁移管理

**Slide 9 — 数据流程图（量表评估完整链路）**

```
医生端                     患者端                    后端
  │                          │                        │
  │ 1. 创建问卷模板           │                        │
  │──────────────────────────────────────────────────►│
  │ 2. 分配任务包             │                        │
  │   生成6位访问码           │                        │
  │──────────────────────────────────────────────────►│
  │                          │                        │
  │                    3. 访问码登录                   │
  │                          │───────────────────────►│
  │                          │ 4. 完成量表/辅助任务    │
  │                          │ (B类/C类)              │
  │                          │───────────────────────►│
  │                          │              5. 后端评分│
  │                          │              自动分析   │
  │ 6. 查看结果、复核评分     │                        │
  │◄──────────────────────────────────────────────────│
```

**Slide 10 — 安全设计**

- API密钥加密存储：`SHA256(LLM_SECRET_KEY) → Fernet(AES-128)`
- JWT Token认证，角色权限（admin/doctor/viewer）
- 患者端免注册，访问码限时
- API响应永不返回完整密钥（掩码显示）

## 第四部分：功能介绍（约 12 张）

### 4.1 医生端

**Slide 11 — 登录 & 仪表盘**
- JWT登录（admin/doctor双角色）
- 仪表盘展示：患者总数、性别分布饼图、年龄分布柱状图、任务完成度进度条
- **截图**：仪表盘页面（`/dashboard`），含ECharts图表

**Slide 12 — 患者管理**
- 100个演示患者（P0001-P0100，自动生成）
- 患者档案：姓名、性别、出生日期、联系方式、主诉、病史、用药史、过敏史
- 搜索与筛选，临床记录管理
- **截图**：患者列表（`/patients`）+ 患者详情页（展开侧边信息）

**Slide 13 — 问卷模板管理**
- JSON Schema定义问卷结构
- 版本管理：草稿 → 发布 → 停用
- 导入治理：预览 → content_hash验证 → 正式导入（防并发冲突）
- 预置模板：SCD问卷、Wellbeing问卷
- **截图**：问卷管理页（`/questionnaires`），展示版本列表和状态标签

**Slide 14 — 任务分配**
- 组合多个问卷/辅助任务为一个任务包
- 生成6位数字访问码，设置截止日期
- 进度跟踪：未开始 / 进行中 / 已完成
- **截图**：创建派发页（`/assignments/new`）+ 访问码展示区域

**Slide 15 — 评估复核（医生审阅辅助任务）**
- 查看患者原始答卷
- 自动分析结果展示（`auto_result`）
- B类/C类任务证据展示（结构化卡片）
- 医生输入各维度评分、风险等级（低/中/高）、备注
- **截图**：评估详情页，展示SCD结构性问卷认知域卡片和自动分析区块

---

### 4.2 患者端

**Slide 16 — 患者端入口（免注册访问码登录）**
- 无需注册，仅凭6位访问码登录
- 任务包列表，各量表进度可见
- **截图**：患者登录页 + 任务包列表页（展示各量表图标和状态）

**Slide 17 — A类：基础自评问卷**
- SCD问卷（主观认知下降评估）
- Wellbeing问卷（情绪与生活质量）
- 题型：单选、多选、量表、长文本
- 草稿自动保存，幂等提交（防重复）
- **截图**：动态答题页，展示题目渲染和进度条

**Slide 18 — B类：Boston图片命名测试**
- 图片识别任务（标准临床图片素材）
- 自动评分规则：完全匹配1分 / 同义词1分 / 模糊匹配0.5分
- 即时反馈，结果自动上报
- **截图**：Boston测试界面（图片展示区 + 输入框）

**Slide 19 — B类：STT形状连线测试**
- **A卷**：数字1-25，25个节点
- **B卷**：数字+字母交替，49个节点
- 两阶段：练习（8/15节点）+ 正式测试
- 年龄分层阈值判读（50-59、60-69、70-79岁）
- 记录：点击轨迹、时间戳、错误次数、纠正次数
- 可视化回放：SVG轨迹图、错误标记
- **截图**：连线画布（展示节点图和已绘连线）+ 结果展示

**Slide 20 — B类：SCD结构性问卷（4阶段智能交互）**
- **阶段1**：多选存在问题的认知域（5个：记忆、语言、组织/计划、注意力、其他）
- **阶段2**：每域1个主要问题 + 5个追加问题（A-E）；智能分支——主要问题回答"是"才展示追加
- **阶段3**：知情者问卷（可用性 + 6题观察 + 关系选择）
- **阶段4**：4题补充信息
- 进度条实时更新，提交前二次确认
- **截图**：
  - 阶段1 认知域多选界面
  - 阶段2 主要+追加问题展开（对比折叠/展开状态）
  - 阶段3 知情者问卷

**Slide 21 — C类：SCD结构化AI访谈**
- 基于患者基础答卷自动生成个性化追问
- 多轮对话（DeepSeek API）
- AI生成结构化访谈小结
- 降级机制：API不可用时自动回退本地规则引擎（标注 `source: "local_fallback"`）
- **截图**：AI对话界面（对话气泡 + 输入框）+ 访谈小结展示

**Slide 22 — C类：MoCA-B开放题AI评分**
- 延迟回忆任务：患者输入所记单词
- 流畅性任务：患者输入动物名称
- DeepSeek语义评分（非关键词匹配）+ 评分理由文本
- 结果供医生复核
- **截图**：MoCA开放题输入界面 + AI评分结果（含理由文本）

**Slide 23 — 系统管理（LLM配置 + 用户管理）**
