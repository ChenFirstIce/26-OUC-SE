# 问卷扩展指南

## 新增简单问卷

1. 复制 `samples/questionnaire-template.example.json`。
2. 修改问卷编码、名称、分区和题目。
3. 以管理员身份调用 Swagger 中的 `POST /api/v1/questionnaires`。
4. 确认预览内容后调用 `POST /api/v1/questionnaires/{id}/publish`。
5. 医生刷新“派发问卷”页面即可选择新模板。

问卷页面根据 JSON 自动渲染，不需要新增 Vue 页面。

## 支持的题型

`short_text`、`long_text`、`integer`、`number`、`date`、`time`、`duration`、`yes_no`、`single_choice`、`multi_choice`、`scale`。

每题必须有全问卷唯一且版本间尽量稳定的 `key`。标准量表题目发布后不应直接修改，应复制为新版本。

## 计分

- `metadata_sum`：选项中配置 `score`，后端自动计算题目分、维度分和总分。
- `manual_review`：只收集答案，提交后显示“待医生复核”。
- 复杂计分：在 `backend/app/services/scoring.py` 注册明确版本的计算器，并补充单元测试；禁止使用 `eval`。

风险阈值从小到大配置。只有取得正式评分手册后才能为临床量表配置阈值。

## 条件显示

第一版支持等值条件：

```json
"show_if": {
  "question_key": "has_change",
  "equals": "yes"
}
```

后端提交校验和前端显示使用同一份模板版本。隐藏题不参与必填校验和计分。
