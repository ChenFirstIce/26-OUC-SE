1. github
   - git clone git@github.com:ChenFirstIce/26-OUC-SE.git
   - 每个人创建自己的分支
     - 创建并切换：git switch -c 名字缩写
     - 拉取主分支代码
       - 拉取主分支的最新代码并合并：git pull origin main
       - 先拉取，后合并
         - 拉取：git fetch origin
         - 查看差异：git log HEAD..origin/main --oneline
         - 合并：git merge origin/main
