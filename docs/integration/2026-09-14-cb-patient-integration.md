# C/B 量表患者系统整合记录

日期：2026-09-14

基础版本：`origin/main`

工作分支：`cyf`

## 已完成内容

### 1. 接入正式患者系统

- 将 C/B 辅助任务接入现有 Vue 患者端，统一使用 `/p/fill/:token` 入口。
- 接入患者访问码验证、患者会话、医生派发任务包和任务状态管理。
- 支持患者开始任务、保存草稿、恢复进度和正式提交。
- 提交接口加入 revision 冲突保护和幂等提交控制。

### 2. 后端数据闭环

- 辅助任务的患者回答和过程数据写入正式数据库。
- 区分程序核验结果、AI 候选结果和医生最终结果，患者提交不会直接形成最终临床评分。
- 保存结构化访谈的会话和消息记录。
- 服务端核验患者任务归属、提交状态和过程数据，不直接信任前端提交的计分结果。

### 3. 医生复核功能

- 医生可以查看患者逐题答案和辅助任务过程记录。
- 支持填写最终总分、维度得分、风险等级和复核意见。
- 支持保存候选结果和确认最终结果。
- 记录复核人、复核时间和复核操作历史。
- 支持填写原因后退回患者重做，并在退回前保留原答卷和复核快照。
- 保存、确认和退回操作均进行权限检查并写入审计日志。

### 4. 复核界面完善

- 将原始过程数据转换为可读展示，不再以大段 JSON 作为主要界面。
- 不同辅助任务使用对应的答案、对话、过程或轨迹展示方式。
- 维度名称改为当前量表版本配置提供的下拉选项，不能自由输入。
- 显示维度分数范围，并限制分数的最小值和最大值。
- 同一维度不能重复选择；配置外的维度会被后端拒绝。
- 总分范围、风险等级和复核意见要求由当前量表版本配置控制。

### 5. 待复核工作台

- 医生首页增加待复核任务列表。
- 按提交时间展示患者、量表、提交时间和等待时长。
- 支持从工作台直接定位到对应任务的复核界面。
- 待复核数据按照医生的数据权限范围过滤。

### 6. STT 过程记录

- 患者端使用节点画布完成连线任务，并实时展示正确路径和错误反馈。
- 保存点击节点、目标节点、相对时间、坐标、顺序、错误次数和累计用时。
- 刷新页面后可以恢复任务进度和计时。
- 服务端根据锁定版本重新计算路径正确性、错误次数和纠正次数。
- 医生端支持查看轨迹图和逐次点击时间线。

### 7. 数据模型、接口与文档

- 增加医生复核字段和只追加的复核历史记录表。
- 增加辅助任务提交、医生复核、退回重做和待复核统计接口。
- 增加并更新数据库迁移文件。
- 更新 `contracts/API.md` 中的接口契约。
- 增加相应的后端回归测试。
