# 七、你们给后端的数据不要只有“分数”

这一点非常重要。

你刚才说：

> 最终给患者后端的是量化数据，比如这题拿多少分。

我建议改成：

> **原始回答 + 前端指标 + 初步分数**

统一成：

```json
{
  "assignmentId": "asg_10001",
  "assessmentId": "gds15",

  "startedAt": "2026-09-01T10:20:00",
  "completedAt": "2026-09-01T10:24:21",

  "answers": [
    {
      "questionId": "q1",
      "value": true,
      "score": 1
    },
    {
      "questionId": "q2",
      "value": false,
      "score": 0
    }
  ],

  "result": {
    "rawScore": 6
  },

  "metrics": {
    "durationMs": 261000
  }
}
```

为什么一定保留 `answers`？

以后如果老师说：

> 我修改了计分规则怎么办？

如果数据库只有：

```text
6 分
```

那完蛋了。

如果保留原始答案：

```text
q1=true
q2=false
...
```

后端重新计算一次就好了。

这也非常符合你们文档里面“**将量表数据结构化保存**”的需求。

而且正式架构上建议：

```text
前端：计算 provisionalScore
后端：重新校验 authoritativeScore
```

不要完全信任浏览器传来的 score。
