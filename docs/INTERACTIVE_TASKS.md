# B2. STT 形状连线

## 资料要点

- STT-A：按数字顺序连接。
- STT-B：按数字顺序连接，同时两种图形交替。
- 要记录用时。
- 做错时应尽快提示并从前一个正确位置继续。
- STT-B 中找不到下一个数字约 10 秒后可提示位置，提示次数记录但不作为错误分。

## Web 实现

使用 SVG，不使用重量级 Canvas 框架。

配置拆分：

```ts
{
  nodes: [{ id, label, shape, x, y }],
  correctSequence: [...],
  mode: 'A' | 'B'
}
```

交互记录：

```ts
{
  sequence,
  startedAt,
  completedAt,
  durationMs,
  errorCount,
  hintCount,
  completed
}
```

UI 参考：

- `../assets/stt_form_a_reference.png`
- `../assets/stt_form_b_practice_reference.png`
- `../assets/stt_form_b_test_reference.png`

首版不要求像素级复制纸质量表，只需保留“节点分散 + 顺序连接 + 形状交替”的任务机制。

# C1. SCD 结构化访谈（AI Mock）

资料中的首轮认知域：

- 记忆力
- 语言 / 找词困难
- 组织能力 / 计划能力
- 注意力 / 专心
- 其他认知功能

主要问题若回答“是”，需要继续收集：

- A：是否担心
- B：什么时候开始变差（近 6 个月 / 6 个月-2 年 / 2-5 年 / 超过 5 年 / 不清楚）
- C：是否觉得比同龄人差
- D：是否因此看过医生/谈过这个问题
- E：第一次与医生谈这些问题是什么时候

## 首版设计

做成聊天式 UI，但 mock API 的本质可以是有限状态机，不需要真 LLM。

`POST /api/mock/interview/:sessionId/message` -> 返回 `reply + nextField + progress`。

最终结构化输出上述字段，并同时保留 conversation transcript。

# 医疗表述限制

AI mock 页面可以显示：

- “回答已记录”
- “评估数据已提交”
- “该结果将供专业人员进一步参考”

- “你患有阿尔茨海默病”
- “AI 已确诊”
- 任何无人工复核的确定性医学判断
