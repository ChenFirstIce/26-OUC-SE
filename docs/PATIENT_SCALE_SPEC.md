# A1. SCD-Q9

## 题型

- Q1/Q2/Q3/Q6/Q8/Q9：是/否
- Q4/Q5/Q7：经常/偶尔/从未

## 题目

1. 你认为自己有记忆问题吗？
2. 你回忆 3-5 天前的对话有困难吗？
3. 你觉得自己近两年有记忆问题吗？
4. 下列问题经常发生吗：忘记对个人来说重要的日期（如生日等）？
5. 下列问题经常发生吗：忘记常用号码？
6. 总的来说，你是否认为自己对要做的事或要说的话容易忘记？
7. 下列问题经常发生吗：到了商店忘记要买什么？
8. 你认为自己的记忆力比 5 年前要差吗？
9. 你认为自己越来越记不住东西放哪儿了吗？

## 评分

- 是 = 1，否 = 0
- 经常 = 1，偶尔 = 0.5，从未 = 0
- 总分 = 各题得分之和

## 推荐配置

`id: scd-q9`，预计 3-5 分钟，一屏一题。

# A2. GDS-15 老年抑郁量表

## 指导语

选择过去一周内最适合你的答案。每题回答“是”或“否”。

## 题目

1. 你对你的生活基本满意吗？
2. 你是否已经放弃了许多爱好与兴趣？
3. 你是否觉得生活空虚？
4. 你是否感到厌倦？
5. 你是否大部分时间精力充沛？
6. 你是否害怕会有不幸的事落到你头上？
7. 你是否大部分时间感到幸福？
8. 你是否经常感到孤立无援？
9. 你是否愿意呆在家里而不愿去室外做些新鲜事？
10. 你是否觉得记忆力比以前差？
11. 你觉得现在活着很开心吗？
12. 你是否觉得像现在这样活着毫无意义？
13. 你觉得生活充满活力吗？
14. 你是否觉得你的处境已毫无希望？
15. 你是否觉得大多数人比你强得多？

| 6 | 是 |
| 7 | 否 |

# A3. ESS 爱泼沃斯嗜睡量表

## 指导语

在下列情况下你打瞌睡或睡着的可能性有多大？

- 0：不会打瞌睡
- 1：打瞌睡的可能性很小
- 2：打瞌睡的可能性中等
- 3：很可能打瞌睡

## 8 个场景

1. 坐着阅读书刊时
2. 看电视时
3. 在沉闷公共场所坐着不动时（如剧场、开会）
4. 连续乘坐汽车 1 小时无间断
5. 条件允许情况下，下午躺下休息时
6. 坐着与人谈话时
7. 未饮酒午餐后安静地坐着
8. 遇到堵车，在停车的几分钟里

## 评分

每题直接取 0/1/2/3，合计总分。评分手册列出 >6、>11、>16 的参考阈值；患者端不要把这些阈值包装成确诊结果。

## UI

每题显示四张大卡片，不使用小 radio。

# A4. 爱丁堡利手量表

## 10 个动作

1. 写字
2. 画画
3. 扔东西
4. 用剪子
5. 刷牙
6. 用刀子
7. 用勺子
8. 梳头
9. 划火柴
10. 打开瓶盖

每项选择：左手 / 右手 / 双手。

## 评分

原表规则：哪侧手完成动作，该侧得 2、另一侧得 0；双手均可完成则左右各 1。

结果公式：

`100 × (右侧总分 - 左侧总分) / (右侧总分 + 左侧总分)`

结果参考：

- < -40：左利手
- -40 ~ +40：双利手
- > +40：右利手

# 配置实现要求

这四套量表必须全部通过统一 `AssessmentDefinition` 配置渲染。推荐：

```ts
type QuestionType =
  | 'boolean'
  | 'single-choice'
  | 'multiple-choice'
  | 'scale'
  | 'number'
  | 'text'
  | 'date'
  | 'time'
```

评分函数放在定义层/纯函数层，不要散落在 React JSX 中。
