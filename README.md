# 阿尔茨海默症筛查问卷与数据统计系统

这是一个真实前后端联通的课程展示系统，已经跑通：

```text
医生登录 -> 创建患者 -> 派发问卷 -> 生成链接/二维码/访问码
-> 患者手机填写并自动保存 -> 提交和规则计分 -> 医生查看 -> 统计更新
```

> 医学声明：当前自带题目均为“非临床演示内容”，不能代替正式量表、医生面诊或医学诊断。正式量表必须根据授权模板和评分手册另行导入。

## 一、第一次运行

需要安装：

- Python 3.12
- Node.js 20 或更高版本

在本项目根目录打开 PowerShell，依次运行：

```powershell
.\scripts\setup.ps1
.\scripts\start.ps1
```

看到“系统启动成功”后打开：

- 医生/管理端：<http://127.0.0.1:5173/login>
- 患者演示端：以 `start.ps1` 输出的“患者手机端”局域网地址为准。
- 后端接口文档：<http://127.0.0.1:8000/docs>

演示身份：

| 身份 | 账号/链接 | 密码/访问码 |
|---|---|---|
| 医生 | `doctor1` | `Doctor123!` |
| 管理员 | `admin` | `Admin123!` |
| 患者 | 演示患者链接 | `123456` |

停止系统：

```powershell
.\scripts\stop.ps1
```

## 二、推荐演示流程

1. 用 `doctor1` 登录。
2. 进入“患者管理”，可以新建匿名患者，或选择 `P0001`。
3. 点击“派发问卷”，选择两个演示问卷并生成填写入口。
4. 让患者扫描页面二维码，或复制患者链接和访问码。
5. 在手机尺寸浏览器中打开患者链接，输入 `123456`。
6. 填写第一份问卷，等待页面显示“已自动保存”；刷新页面可看到答案仍存在。
7. 提交问卷，再完成第二份问卷。
8. 回到医生端查看患者评估时间线和数据总览。
9. 点击图表“导出 PNG”，或调用统计 CSV 导出接口。

### 手机扫码条件

- 手机与电脑必须连接同一个 Wi-Fi/局域网。
- 启动时系统会自动检测电脑局域网 IP，并把它写入新派发任务的二维码。
- Windows 首次询问防火墙权限时，需要允许 Node.js 访问“专用网络”。
- 二维码不得使用 `127.0.0.1`；该地址在手机上表示手机自身。
- 如果学校网络开启客户端隔离，手机不能直接访问电脑，需要改用电脑热点或 HTTPS 隧道。

## 三、开发与测试

后端单独运行：

```powershell
Set-Location .\backend
python run.py
```

前端单独运行：

```powershell
npm run dev --prefix .\frontend
```

执行完整检查：

```powershell
.\scripts\test.ps1
```

当前自动化测试覆盖登录、患者创建、问卷派发、患者验证、草稿保存、幂等提交、计分、统计更新和跨医生越权拦截。

## 四、模块边界

- `backend/app/routers`：HTTP 参数、身份依赖和响应。
- `backend/app/services`：题目校验、计分、派发状态和审计业务逻辑。
- `backend/app/models.py`：数据库持久化模型。
- `frontend/src/api`：统一接口客户端。
- `frontend/src/stores`：当前登录身份。
- `frontend/src/views`：医生/管理页面。
- `frontend/src/views/patient`：患者移动填写页面。
- `frontend/src/components`：统计图和动态题目等公共组件。

新增简单量表时，优先增加问卷 JSON、选项分值和风险配置，不修改患者填写页面。复杂量表为后端计分服务新增明确命名、带版本和单元测试的计算器。

## 五、数据位置与安全

由于当前 Windows Python 运行时不能让 SQLite 打开包含中文的工作区路径，默认数据库放在：

```text
%TEMP%\ad_questionnaire_data\ad_questionnaire.db
```

可通过 `DATABASE_URL` 改用 ASCII 路径或 PostgreSQL。生产或联网前必须更换 `JWT_SECRET`、演示密码和患者访问机制。

当前演示数据全部匿名，不应录入真实姓名、身份证、手机号或家庭住址。

更完整的需求、数据和验收规范见 [项目规范与Codex执行任务.md](./项目规范与Codex执行任务.md)。
